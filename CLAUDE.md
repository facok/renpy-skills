# Ren'Py Skills Pack

A collection of Claude Code skills for Ren'Py visual novel development.

## Skills Overview

| Skill | Directory | Trigger |
|---|---|---|
| `renpy` | `renpy/` | General Ren'Py development, project scaffolding, script writing, dialogue, branching, characters, transitions, audio, saves |
| `renpy-rpg` | `renpy-rpg/` | RPG stats, leveling, XP, equipment, turn-based combat, skill checks |
| `renpy-maps` | `renpy-maps/` | World maps, location navigation, travel systems, area unlocks |
| `renpy-minigames` | `renpy-minigames/` | Embedded minigames: puzzles, rhythm, cards, timed prompts |
| `renpy-screens` | `renpy-screens/` | Screen Language, custom UI, HUDs, menus, modal dialogs |

## Routing Rules

- Start with `renpy` (main skill) for any Ren'Py project discussion.
- Route to subsystem skills only when the user explicitly asks about or is implementing that specific feature.
- All skills are self-contained; no cross-file dependencies at runtime.
